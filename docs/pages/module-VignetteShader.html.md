# VignetteShader

## Import

VignetteShader is an addon, and must be imported explicitly, see [Installation#Addons](../../manual/#en/installation).

```js
import { VignetteShader } from 'fourjs/addons/shaders/VignetteShader.js';
```

## Properties

### .VignetteShader : ShaderMaterial~Shader (inner, constant)

Based on [PaintEffect postprocess from ro.me](https://github.com/dataarts/3-dreams-of-black/blob/master/deploy/js/effects/PaintEffect.js).
