# AfterimageShader

## Import

AfterimageShader is an addon, and must be imported explicitly, see [Installation#Addons](../../manual/#en/installation).

```js
import { AfterimageShader } from '@tnb1j/4js/addons/shaders/AfterimageShader.js';
```
