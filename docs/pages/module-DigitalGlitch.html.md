# DigitalGlitch

## Import

DigitalGlitch is an addon, and must be imported explicitly, see [Installation#Addons](../../manual/#en/installation).

```js
import { DigitalGlitch } from '@fourjs/core/addons/shaders/DigitalGlitch.js';
```

## Properties

### .DigitalGlitch : ShaderMaterial~Shader (inner, constant)

Digital glitch shader.
